## About

Saya DevOps-leaning developer yang fokus di satu hal: **menghilangkan kerjaan manual dari muka bumi.**

Kalau sebuah proses bisa di-script, di-cron, atau di-container - saya akan lakukan itu, bukan karena rajin, tapi karena males ngulangin hal yang sama tiap minggu.

```yaml
principles:
  - "If it's repetitive, automate it."
  - "If it can break, add retry + logging."
  - "If it works, don't touch it."
  - "If it doesn't work, blame the cloudflare tunnel first."
```
