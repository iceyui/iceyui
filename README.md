## About

DevOps-leaning developer focused on one mission: **eliminating manual work.**

If a process can be scripted, cron'd, or containerized, I'll do it - not because I'm diligent, but because I refuse to repeat the same task every week.

```yaml
principles:
  - "If it's repetitive, automate it."
  - "If it can break, add retry + logging."
  - "If it works, don't touch it."
  - "If it doesn't work, blame the cloudflare tunnel first."
```
